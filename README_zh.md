## ✨ 核心功能

### 🔮 AI预测引擎™

获取综合技术面、基本面、新闻和机构情绪（COT）的多日市场预测。预测引擎使用多因子算法，结合技术分析、基本面指标、最新新闻市场情绪和交易者持仓（COT）数据，提供全面且可衡量的预测。每个预测都附带信心水平和场景范围，帮助您做出更明智的决策。

### 🧠 自主AI分析师

24/7 AI扫描市场并识别高信念设置。自主分析师持续运行，监控各种工具和市场，寻找符合您高信念设置标准的交易机会。当发现机会时，AI发送包含完整分析的通知，包括入场理由、盈利目标、止损和风险评估。

### 📲 交互式WhatsApp机器人

使用简单命令随时随地获取预测和信号。WhatsApp机器人允许您从任何地方与AI交易计划交互，无需打开应用程序。发送文本命令即可直接在手机上获取预测、最新信号或实时市场分析。

### 🐍 Python客户端和Colab

以编程方式与您的AI交互，进行高级数据分析和回测。Python客户端提供编程接口，允许您从Python脚本或Google Colab笔记本访问AI交易计划的所有功能。非常适合策略回测、历史数据分析和自定义交易算法开发。

### 📈 实时可视化

"纪律仪表板"配有高级动画图表。可视化实时显示资金曲线、盈亏分布、一致性日历连续性和交易绩效指标，格式直观且交互式。所有图表在新的交易数据进入时实时更新。

### 👁️ 嵌入TradingView图表

直接在应用内分析图表。嵌入的TradingView小部件允许您直接在应用内进行技术分析，无需离开，可访问各种指标、绘图工具和时间框架。

### 🧘‍♂️ 情绪智能

追踪您的情绪并获得游戏化反馈以强化纪律。情绪智能系统监控您的交易情绪，识别有害行为模式，如情绪化过度交易或亏损后的报复性交易，并提供及时干预。自动情绪锁定功能可在系统检测到您不在最佳心理状态时禁用交易。

### 🎤 语音聊天

免提与您的AI教练交互。语音聊天功能允许您仅通过语音获取市场分析、记录交易日志和接收交易建议——非常适合您双手忙于监控图表的情况。

## 🏗️ 系统架构

Dhaher Trading Plan AI采用多平台架构，核心组件包括：

- **Flutter应用**：iOS和Android跨平台移动应用
- **Google Apps Scripts**：与Google Sheets集成的轻量后端
- **WhatsApp机器人**：基于Node.js的聊天界面
- **Python客户端**：用于高级分析的编程客户端
- **AI服务**：与GPT和其他AI服务的集成

详见[ARCHITECTURE.md](ARCHITECTURE.md)了解完整架构文档。
