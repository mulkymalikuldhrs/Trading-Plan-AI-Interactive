# Contributing to Dhaher Trading Plan AI

Terima kasih atas minat Anda untuk berkontribusi pada proyek Dhaher Trading Plan AI! Dokumen ini menyediakan panduan untuk kontribusi.

---

## 🚀 Memulai

1. Fork repositori
2. Buat branch fitur (`git checkout -b feature/amazing-feature`)
3. Buat perubahan Anda
4. Commit menggunakan conventional commits (`git commit -m "feat: add amazing feature"`)
5. Push ke fork Anda
6. Buka Pull Request

---

## 📝 Format Pesan Commit

Kami menggunakan [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` - Fitur baru
- `fix:` - Perbaikan bug
- `docs:` - Perubahan dokumentasi
- `style:` - Perubahan gaya kode (formatting)
- `refactor:` - Refactoring kode
- `test:` - Menambah atau memperbarui test
- `chore:` - Tugas pemeliharaan

---

## 🧪 Testing

Sebelum mengirim PR, pastikan:

- Semua test yang ada masih lulus
- Tambahkan test untuk fitur baru
- Kode mengikuti gaya yang konsisten dengan kode yang ada

---

## 🐛 Melaporkan Masalah

Saat melaporkan masalah, harap sertakan:

- Deskripsi yang jelas tentang masalah
- Langkah-langkah untuk mereproduksi
- Perilaku yang diharapkan vs aktual
- Detail lingkungan (OS, versi Python/Node, dll.)
- Screenshot jika memungkinkan

---

## 📋 Proses Code Review

1. Semua PR memerlukan review sebelum digabungkan
2. CI checks harus lulus
3. Dokumentasi harus diperbarui jika diperlukan
4. Test harus ditambahkan untuk fitur baru

---

## 🎯 Area Kontribusi

Kami menyambut kontribusi dalam area berikut:

- **Fitur Baru**: Implementasi fitur yang dijelaskan dalam TODO.md
- **Bug Fix**: Perbaikan bug yang dilaporkan dalam Issues
- **Dokumentasi**: Peningkatan dokumentasi, tutorial, dan panduan
- **Terjemahan**: Terjemahan ke bahasa tambahan
- **UI/UX**: Peningkatan antarmuka pengguna dan pengalaman
- **Performa**: Optimasi kecepatan dan penggunaan sumber daya
