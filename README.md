## 🇬🇧 English

### ✨ Core Features

- 🔮 **AI Forecast Engine™** — Multi-day market forecasts synthesizing technicals, fundamentals, news, and COT
- 🧠 **Autonomous AI Analyst** — 24/7 AI scanning markets for high-conviction setups
- 📲 **Interactive WhatsApp Bot** — Get forecasts and signals on the go
- 🐍 **Python Client & Colab** — Programmatic AI interaction for advanced analysis
- 📈 **Live Visualizations** — "Dashboard of Discipline" with animated charts
- 👁️ **Embedded TradingView Charts** — Live chart analysis in-app
- 🧘‍♂️ **Emotional Intelligence** — Mood tracking with gamified feedback
- 🎤 **Voice-Enabled Chat** — Hands-free AI coach interaction

### 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/mulkymalikuldhrs/Trading-Plan-AI-Interactive.git

# Flutter App
cd flutter_app
flutter pub get
flutter run

# Python Client
cd python_client
pip install -r requirements.txt
```
